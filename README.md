# HipfireRDR1 0.2.5 Series

0.2.4 подтверждена пользователем: анимация и направление работают правильно.
0.2.5 сохраняет этот механизм и добавляет повторные запросы при удержании
ЛКМ, с ожиданием готовности оружия.

[Скомпилированный HipfireRDR1.red](HipfireRDR1.red) или
[архив 0.2.5 Series](HipfireRDR1-0.2.5-Series.zip).
Закройте игру, замените .red рядом с RDR.exe и удерживайте ЛКМ без ПКМ.
[Полная инструкция](HIPFIRE-INSTALL.md).

Сборка и тесты прошли; серия в настоящей игре ещё не проверена.
Очень короткий щелчок по-прежнему может не успеть дать первый выстрел.

Для записи серии можно оставить Capture: F10, удерживать ЛКМ,
отпустить, F11. Старый комплект Capture 0.1 содержит прежний мод 0.2.2;
для этой проверки используйте новый HipfireRDR1.red.
Пользовательские логи не публикуются.
