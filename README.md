# HipfireRDR1

**0.2.10 Fresh Series:** ожидающие клики больше не переносятся через
перезарядку. Очередь ограничивается текущим зарядом, очищается после
1,8 секунды без выстрелов и при перемещении после простоя. После
перезарядки нужен новый отдельный клик ЛКМ.

Механизм позы и исправления 0.2.9 сохранены. Один отдельный клик
добавляет один запрос, удержание не добавляет повторов. Серии на
6, 9 и 15 патронов проверены на модели оружия; нормальное выполнение
длинной серии не прерывается общим возрастом её запросов.

Сборка, тесты очереди/отмены/позы и эмуляция перехвата пройдены.
Версия 0.2.10 в самой игре ещё не проверена.
[Установка, управление и ограничения](HIPFIRE-INSTALL.md).

Пользовательские логи и материалы исследования не публикуются.
