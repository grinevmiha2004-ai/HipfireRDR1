# HipfireRDR1

**0.2.12 Task Lifetime:** исправлено преждевременное завершение задачи
выстрела. Параметр 0.25 оказался временем жизни в секундах, тогда как
фактический выстрел обычно происходил примерно через 280 мс. Теперь
задача живёт до 800 мс и очищается после подтверждённого выстрела.

Один клик добавляет один запрос, удержание не создаёт повторов.
Используются фактический заряд Ле Ма в девять патронов, прежняя поза
и игровая точка прицела. Очередь не переживает перезарядку или долгий
простой. Журнал дополнен сравнением точки ПКМ и состоянием R.

Сборка, модельные тесты и эмуляция реального таймера/перехвата пройдены.
Версия 0.2.12 в самой игре ещё не проверена; точное совпадение попаданий
с ПКМ и устранение всех обрывов серии пока не подтверждены.
