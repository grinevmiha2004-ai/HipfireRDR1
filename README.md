# HipfireRDR1 0.2.2 Experimental

Возврат к механизму 0.2: узел Dead Eye `PistolHoldStand` и немедленная
штатная задача выстрела `TASK_SHOOT_AT_COORD` с прежним параметром 0.25.
Время до освобождения задачи — 300 мс, интервал нажатий — 350 мс.
Пользователь подтвердил нужную анимацию в исходной 0.2.

В 0.2.1 сохранение прежнего угла тела не устранило разворот, хотя
пользователь подтвердил стрельбу от бедра. Прежний угол тела может не
совпадать с направлением камеры.

В 0.2.2 угол тела задаётся горизонтальным направлением камеры на момент
нажатия. Выравнивание выполняется перед задачей выстрела и поддерживается
в её прежнем 300-мс окне. Используется atan2(direction.x, direction.z),
соответствующий матрице SET_ACTOR_HEADING в предоставленном RDR.exe.
При строго вертикальном взгляде сохраняется прежний угол тела.
Путь анимации, точка цели и тайминги сохранены от 0.2.

Проверены сборка, параметры и порядок вызовов natives. Построение матрицы
направления проверено эмуляцией функции из пользовательского EXE для
шести направлений. Это не проверяет анимацию и порядок обновлений игры.
Устранение видимого разворота ещё требует проверки в настоящей игре;
дополнительный поворот внутри анимации пока не исключён.

## Установка

1. Закройте игру.
2. Замените `HipfireRDR1.red` рядом с `RDR.exe` файлом из этого архива.
   Уберите старый `HipfireRDR1-Diagnostic.red` или `.asi`, если он остался.
3. Загрузите игру, встаньте пешком вне укрытия с револьвером или пистолетом
   в руке. Нажмите ЛКМ без удержания ПКМ.
4. F7 включает/выключает мод. ПКМ отменяет его действие.

Нужен установленный RedHook 0.8. Загрузчики и игровые архивы менять не нужно.
На время выстрела тело выравнивается по горизонтальному направлению камеры
на момент нажатия; цель выстрела задаётся как в 0.2.

Проверить в игре: сохранилась ли анимация 0.2, исчез ли разворот,
правильно ли летят пули и работает ли обычное прицеливание через ПКМ.

Для удаления закройте игру и удалите `HipfireRDR1.red`.
Перед горячей выгрузкой выключите мод F7 и подождите секунду.

## Исходники

В каталоге `source`: Windows — `scripts\build-hipfire-msvc.cmd` из x64 Native
Tools Command Prompt; Linux с MinGW — `bash scripts/build-hipfire.sh`.
Тесты: `g++ -std=c++17 -I tests/support tests/native_calls.cpp -o native_calls_test`
и `./native_calls_test`.
