# HipfireRDR1

**0.2.11 LeMat & Reticle:** исправлен таймер, который мог прерывать уже
начатый выстрел и обрывать серию. Ле Ма использует фактический заряд
в девять патронов. Добавлено наведение на игровую мировую точку прицела
с проверкой корректности и возвратом к прежнему лучу при её отсутствии.

Один отдельный клик добавляет один запрос; удержание не создаёт повторов.
Правила отмены старых кликов после перезарядки, простоя и перемещения
сохранены. Поза и исправленная ориентация прежние.

Сборка, тесты серий 6/9/15, регрессии Ле Ма с прерыванием после четвёртого
выстрела и эмуляция игровых обработчиков пройдены. Версия 0.2.11 в самой
игре ещё не проверена, включая точное устранение смещения влево.
