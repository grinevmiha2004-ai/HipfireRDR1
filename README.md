# HipfireRDR1

**0.2.7 Combat** сохраняет очередь отдельных кликов ЛКМ и исправляет
её обработку при временных прерываниях в бою. Удержание не добавляет
автоматических выстрелов. Прерванный запрос сохраняется; расход патрона
проверяется перед повторной попыткой. Цель читается с текущей камеры
при запуске выстрела.

Путь позы, исправленный луч камеры и параметры задачи сохранены из
подтверждённой пользователем 0.2.4. Исправлены преждевременное отпускание
спуска и сброс задачи до завершения стрельбы.

Сборка, тесты прерываний/очереди и эмуляция скомпилированного перехвата
пройдены. Версия 0.2.7 в самой игре пока не проверена; устранение всех
случаев обычной анимации прицеливания ещё не подтверждено.
