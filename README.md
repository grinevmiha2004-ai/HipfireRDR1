# HipfireRDR1

**0.2.8 Recovery** заменяет неудачную 0.2.7. Убрано бесконечное ожидание
флага стрельбы, возвращено короткое освобождение задачи из 0.2.6,
добавлена обработка временного номера оружия -1 без удаления очереди.

Один отдельный клик ЛКМ добавляет один запрос. Удержание не создаёт
автоматических повторов. Поза, исправленный луч камеры и параметры
задачи сохранены из подтверждённой пользователем 0.2.4.

Сборка, тесты очереди/зависшего флага/смены оружия и эмуляция перехвата
пройдены. Версия 0.2.8 в самой игре ещё не проверена.
[Установка, управление и ограничения](HIPFIRE-INSTALL.md).

Пользовательские логи и материалы исследования не публикуются.
