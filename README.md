# HipfireRDR1 0.4 — экспериментальная сборка

Переписана логика: запускается клип выстрела с оружием в положении удержания,
затем native создаёт один снаряд текущего оружия. Обычная задача стрельбы
из версий 0.2/0.3 удалена. Это ещё не подтверждённый в игре рабочий мод.

## Установка

1. Закройте игру. Уберите старые HipfireRDR1-Diagnostic.asi/.red, если ставили.
2. Замените HipfireRDR1.red рядом с RDR.exe и RedHook.dll новым файлом.
3. Загрузите свободное перемещение, встаньте пешком вне укрытия и достаньте
   Cattleman (рекомендуется для первой проверки) или другой пистолет/револьвер.
4. Нажмите ЛКМ без ПКМ. F7 включает/выключает мод. ПКМ отменяет его действие.

RedHook 0.8, исходные игровые архивы и настройки загрузчиков заменять не нужно.
Выстрел разрешён только после подтверждения запуска нужного клипа. Если
клип или кость правого запястья не найдены, попытка прекращается без снаряда.

## Что проверить

Положение револьвера, отсутствие разворота спиной, один выстрел и один патрон
на нажатие, звук/вспышку, возврат управления и обычное прицеливание через ПКМ.
Не подтверждены точная анимация исполнения меток Dead Eye и момент вспышки.
Точка ствола пока приближённая — от правого запястья; она может отличаться
от настоящего muzzle_locator. При внутреннем отказе создания снаряда
возможна потеря патрона. Это требует проверки в настоящей игре.

Поддерживается только пешее положение стоя с оружием в руке, вне укрытия,
перезарядки и Dead Eye. Автоматическое доставание, ходьба, бег и стрельба
с лошади пока не реализованы. Интервал попыток — минимум 550 мс.

Для удаления закройте игру и удалите только HipfireRDR1.red. Перед горячей
выгрузкой через консоль RedHook выключите мод F7 и подождите секунду.

## Сборка исходников из source

Windows: scripts\build-hipfire-msvc.cmd из x64 Native Tools Command Prompt.
Linux с MinGW-w64: bash scripts/build-hipfire.sh.
Тесты передачи параметров (Linux):
g++ -std=c++17 -I tests/support tests/native_calls.cpp -o native_calls_test
./native_calls_test
