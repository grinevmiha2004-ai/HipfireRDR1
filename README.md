# HipfireRDR1

**0.2.14 Aim Ray:** механика стрельбы возвращена к лучшей пользовательской
версии 0.2.11. Неудачные изменения 0.2.12 и 0.2.13 отозваны.

Новый расчёт цели ищет ближайшую поверхность и после обычного ПКМ
учитывает измеренное смещение камеры. Один отдельный клик ЛКМ добавляет
один запрос выстрела от бедра.

Сборка и проверки пройдены. Фактические попадания ещё не проверены в игре.
Оставшиеся обрывы серии из 0.2.11 этой правкой отдельно не устранены.
[Установка, сравнение и ограничения](HIPFIRE-INSTALL.md).

Пользовательские журналы и материалы исследования не публикуются.
