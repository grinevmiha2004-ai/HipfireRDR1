# HipfireRDR1 0.2.4 Experimental

Исправлен знак луча точки выстрела: камера смотрит вдоль отрицательной
стороны оси GET_CAMERA_DIRECTION. Прежняя формула ставила цель за спиной,
из-за чего направленная анимация уходила в крайнюю боковую позу.
Узел, клип и тайминги прежние; принудительного прицеливания нет.

[Скомпилированный HipfireRDR1.red](HipfireRDR1.red) или
[архив 0.2.4](HipfireRDR1-0.2.4-Experimental.zip).
Закройте игру и замените HipfireRDR1.red рядом с RDR.exe.
[Полная инструкция](HIPFIRE-INSTALL.md).

Сборка и тесты прошли. Полное визуальное поведение после исправления луча
ещё требует проверки в игре.

## Перехват

[Отдельный Capture.red](HipfireRDR1-Capture.red) можно оставить для проверки.
F10 — обычный режим и выстрелы мода, F11 — остановить/сохранить лог.
Старый полный комплект Capture 0.1 содержит мод 0.2.2; для проверки
нового исправления используйте HipfireRDR1.red из 0.2.4.
Пользовательские логи и подробный разбор не публикуются.
