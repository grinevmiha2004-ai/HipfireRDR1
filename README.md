# HipfireRDR1 0.2.3 Experimental

Сборка для проверки управления корпусом и оружием через состояние игрока.
Пользовательские снимки подтвердили: изменение угла персонажа в 0.2.1
и 0.2.2 не устранило различие позы с Dead Eye. Эти варианты не считать
исправлением разворота.

## Изменение

Удалены все вызовы GET_HEADING и SET_ACTOR_HEADING. Вместо коррекции угла
на время задачи включается SET_FORCE_PLAYER_AIM_MODE(player, true).
При окончании или отмене задачи флаг снимается через тот же native.
Сохранены путь PistolHoldStand, немедленный TASK_SHOOT_AT_COORD, параметр
0.25, время освобождения 300 мс и интервал нажатий 350 мс из 0.2.

В предоставленном RDR.exe обработчик native (RVA 0xAD8230) меняет бит 2
по смещению 0x3BC контроллера игрока. Ветка RVA 0x374849 проверяет этот
бит вместе с обычным состоянием прицеливания и результатом проверки
Dead Eye. Принудительный режим и ветка Dead Eye устанавливают один из
одинаковых флагов оружия (+0x5EA, бит 1). Это проверено ограниченной
эмуляцией кода EXE. Остальные состояния Dead Eye этим не воспроизводятся.
Замедление и сам Dead Eye скрипт не включает.

## Установка

1. Закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe новым файлом.
3. С револьвером или пистолетом в руке, пешком вне укрытия нажмите ЛКМ
   без ПКМ. F7 включает/выключает мод; ПКМ отменяет действие мода.

RedHook 0.8 и игровые архивы менять не нужно. Уберите старый
HipfireRDR1-Diagnostic.red/.asi, если он остался.

## Проверка и пределы

Windows x64 сборка и тесты передачи параметров пройдены. Проверен
настоящий цикл обработки ввода со снятием флага по таймеру, ПКМ, F7,
паузе, потере фокуса и входу в Dead Eye. Проверено снятие при смерти,
невалидном или заменённом актёре. Удержание ЛКМ не повторяет задачу.

Это экспериментальный вариант: в настоящей игре ещё не проверены
поза, видимый поворот корпуса, направление оружия и поведение камеры
при принудительном режиме прицеливания. Эмуляция небольшого фрагмента
EXE и тесты natives не заменяют такую проверку.

Для удаления закройте игру и удалите HipfireRDR1.red. Перед горячей
выгрузкой выключите мод F7 и подождите секунду.

## Исходники

Windows: scripts\build-hipfire-msvc.cmd из x64 Native Tools Command Prompt.
Linux с MinGW: bash scripts/build-hipfire.sh.
Тесты: g++ -std=c++17 -I tests/support tests/native_calls.cpp -o native_calls_test
и ./native_calls_test.
