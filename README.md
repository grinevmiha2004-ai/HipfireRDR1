# HipfireRDR1

**0.2.16 — прицел через RedHook.** Вместо не появившегося текстового символа
используется штатная отрисовка прямоугольников RedHook 0.8: белая точка
с тёмной обводкой. Механика стрельбы и расчёт цели сохранены из 0.2.11.

Точка привязана к проекции цели задачи выстрела; предварительный ПКМ не нужен.
Для неё требуется включённый графический рендерер RedHook.

Сборка и проверки пройдены, включая реальные функции предоставленной
RedHook.dll. Видимость и совпадение с попаданиями ещё не проверены в игре.
[Установка, журнал и ограничения](HIPFIRE-INSTALL.md).
Пользовательские журналы и материалы исследования не публикуются.
