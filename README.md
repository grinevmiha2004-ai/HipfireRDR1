# HipfireRDR1

**0.2.9 Full Series:** проверяет позу после постановки задачи выстрела,
исправляет её раннюю замену обычным прицеливанием и освобождает
неудачную задачу через 800 мс вместо двух секунд. Очередь больше не
останавливается навсегда после трёх неудачных попыток.

Каждый отдельный клик ЛКМ добавляет один запрос. Удержание не создаёт
автоматических повторов. Очередь на 64 запроса учитывает расход патронов;
серии из 6, 9 и 15 коротких кликов проверены на модели оружия.
Путь позы и исправленный луч камеры сохранены из рабочей 0.2.4.

Сборка, тесты серий/переходов и эмуляция перехвата пройдены.
Версия 0.2.9 в самой игре ещё не проверена.
