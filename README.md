# HipfireRDR1

**0.2.15 — прицел-точка на основе 0.2.11.** Восстановлены механика стрельбы
и расчёт цели из лучшей пользовательской версии. Поправки 0.2.14 удалены.

Добавлена белая точка, показывающая цель задачи выстрела без предварительного
ПКМ. При обычном прицеливании и неподдерживаемых состояниях точка скрывается.

Сборка и автоматические проверки пройдены. Совпадение с фактическим
попаданием и отображение в игре пока не проверены. Остаточные обрывы
серий из 0.2.11 сохранены.

[Установка и ограничения](HIPFIRE-INSTALL.md).
Пользовательские журналы и материалы исследования не публикуются.
