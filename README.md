# HipfireRDR1 0.2 — экспериментальный прототип

Это версия с игровыми действиями, не диагностический логгер.
Собрана для Windows x64 / RedHook 0.8. В игре ещё не проверена:
выстрел, анимация, расход патронов и возврат управления не подтверждены.

## Установка

Закройте игру. Уберите прежние HipfireRDR1-Diagnostic.asi/.red, если ставили.
Скопируйте только HipfireRDR1.red рядом с RDR.exe и RedHook.dll.
RedHook.ini и другие загрузчики менять не нужно. act.rpf заменять не нужно.

Пешком, стоя, достаньте револьвер или пистолет. Нажмите ЛКМ без ПКМ.
Прототип пытается включить реальный узел
default_character_Main\Gunplay\Pistol\DeadEye\PistolHoldStand
и поставить персонажу штатную задачу выстрела в направлении камеры.
ПКМ прекращает действие прототипа. F7 включает/выключает его.
Одна отдельная попытка выстрела на нажатие, интервал не меньше 350 мс.

Первая версия ограничена оружием в руке, пешим положением стоя, вне укрытия,
перезарядки и Dead Eye. Доставание оружия из кобуры не реализовано.

## Что именно проверяем

Нужно увидеть: (1) позицию оружия из Dead Eye, (2) настоящий выстрел,
(3) расход патрона, (4) возврат обычного управления после выстрела,
(5) штатное прицеливание по ПКМ. Сообщите, какие пункты получились.
Если задача стрельбы меняет позу либо не работает на игроке, эта сборка
ещё не выполняет цель — отдельного подтверждения hipfire пока нет.

Искусственные пули и имитация ПКМ не используются. Полный режим Dead Eye,
замедление, метки, бесконечные патроны не включаются. Анимационные ресурсы
пользователя и загрузчики в этот пакет не включены.

Для удаления закройте игру и удалите HipfireRDR1.red. Перед выгрузкой
через консоль RedHook отключите мод клавишей F7 и подождите секунду.

## Сборка

Linux/MinGW-w64: bash scripts/build-hipfire.sh

Windows: scripts\build-hipfire-msvc.cmd из x64 Native Tools Command Prompt.
