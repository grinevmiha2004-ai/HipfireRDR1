# HipfireRDR1

**0.2.13 Series Hold:** вместо возврата в обычное дерево после каждого
патрона мод сохраняет позу готовности между запросами стоячей серии.
В конце серии, при отмене и запросе движения удержанная поза снимается.
Параметр задачи 0.25 сохранён из 0.2.11; неудачная 0.2.12 отозвана.

Один отдельный клик добавляет один запрос. Очередь ограничивается
текущим зарядом и не переживает перезарядку или длительный простой.
Тесты серий 6/9/15 и освобождения позы пройдены. В игре 0.2.13 ещё
не проверена; прекращение обрыва после пяти выстрелов не подтверждено.

**Смещение прицела пока не исправлено.** Добавлена сравнительная запись
точки ПКМ и камеры/цели hipfire без изменения игрового наведения.
