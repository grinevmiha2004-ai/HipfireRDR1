# HipfireRDR1 — откат 0.2.3

**0.2.3 отозвана:** пользователь подтвердил оставшийся перекос корпуса
и блокировку управления в режиме прицеливания.

Прямой HipfireRDR1.red возвращён к ранее опубликованной 0.2.2 без
добавленного принудительного прицеливания. Это откат блокировки;
проблема позы в 0.2.2 остаётся. Перед заменой закройте игру.
Скомпилированный .red кладётся рядом с RDR.exe.

Исследование анимаций продолжается. Новое исправление позы не выпущено.
Архивы прежних экспериментов сохранены для истории.


## Перехват для сравнения Dead Eye и мода

[Скачать комплект Capture 0.1](HipfireRDR1-Capture-0.1.zip)
или [отдельный скомпилированный перехват](HipfireRDR1-Capture.red).
[Инструкция](CAPTURE-INSTALL.md): F9 — пометка Dead Eye, F10 — мод,
F11 — остановить и сохранить HipfireRDR1-Capture.jsonl.
Комплект содержит два готовых .red: перехват и ранее опубликованную 0.2.2.
Это сбор данных для исследования, а не новое исправление позы.
В запущенной игре перехват ещё не проверен.
