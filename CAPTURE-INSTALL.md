# HipfireRDR1 Capture 0.1

Отдельный плагин RedHook 0.8 для сравнения анимаций настоящего Dead Eye
и экспериментального мода. Это перехват состояния, а не новая версия hipfire.

## Установка и одна проверка

1. Закройте игру. Положите оба файла `.red` из архива рядом с RDR.exe:
   HipfireRDR1.red и HipfireRDR1-Capture.red. Согласитесь на замену старого
   HipfireRDR1.red: в комплекте известная 0.2.2 без принудительного режима
   прицеливания из неудачной 0.2.3. Старый Diagnostic.red/.asi уберите.
   RedHook.dll, ScriptHookRDR.dll и игровые архивы менять не нужно.
2. Загрузите игру. Пешком вне укрытия достаньте Cattleman.
   Нажмите F9. Включите настоящий Dead Eye, отметьте цели и дайте Джону
   исполнить 2–3 выстрела.
3. Выйдите из Dead Eye. Нажмите F10, затем сделайте 2–3 отдельных нажатия
   ЛКМ без ПКМ — выстрелы нашего мода. F7 оставлен самому моду;
   после запуска игры мод включён по умолчанию.
4. Нажмите F11. Пришлите HipfireRDR1-Capture.jsonl из папки RDR.exe.

F9 и F10 помечают части одного лога. Между ними не перезапускайте игру:
при следующем запуске лог перезаписывается. Каждое окно длится до 30 секунд;
ждать его окончания не нужно. F10 сразу переключает на второй этап.
Потеря фокуса останавливает запись; при необходимости нажмите нужную
метку снова. Лог ограничен 16 МиБ. Интернет и автоматическая отправка не используются.

## Что записывается

Перехватываются вход, обновление и выход AimAnimationTrack для локального
игрока. Каждый оригинальный метод вызывается один раз с исходным объектом;
его результат возвращается игре. Плагин не задаёт угол, позу, выстрел,
патроны, ввод или режим прицеливания.

В лог входят имена hi/mid/lo/fire из определения трека, состояние и флаги
оружия, угловые значения, данные реальных playback-узлов, их текущее время
и ожидаемое изменение времени. Если длительность удаётся однозначно
прочитать из проверенного простого getter, также записывается нормированная
фаза. Неопознанный getter не вызывается: duration_valid=false и фаза null.
Имя разрешённого клипа читается из заголовка +0x10, при недоступной строке
остаётся пустым; адрес класса клипа сохранён для разбора.

События: 0 — снимок скриптового кадра, 1/2 — до/после входа в трек,
3 — после обновления, 4/5 — до/после выхода. Метки: 1 — F9, 2 — F10.
Биты input_bits: 1 — ЛКМ, 2 — ПКМ, 4 — native Dead Eye, 8 — native shooting.
Биты ввода в hook-событии относятся к последнему скриптовому кадру;
внутренние de_mode_raw/de_exec_raw читаются непосредственно в снимке.
Снимки не останавливают другие потоки игры.

## Совместимость и проверки

Перехват предназначен для RDR.exe, ранее предоставленного пользователем
(версия 1.0.40.57107). До установки проверяются заголовок, короткие
сигнатуры шести функций и исходные адреса трёх виртуальных методов.
При несовпадении в логе будет REFUSED, а перехват не установится.
При успешной установке будет READY.

В процессе изменяются только три адреса виртуальных методов; инструкции
EXE на диске не меняются. Для исключения выгрузки DLL во время вызова
плагин закрепляется до завершения процесса. F11 останавливает запись;
для удаления закройте игру и удалите HipfireRDR1-Capture.red.

Проверены Windows x64 сборка, чтение синтетических объектов, отказ на
неверной сигнатуре/версии, обработка недоступных полей и 12 запусков
скомпилированных обёрток в эмуляции Win64 с включённой и выключенной записью.
Обёртки сохраняют объект, результат оригинала и невременные регистры.
В настоящей игре этот перехват ещё не проверен.
