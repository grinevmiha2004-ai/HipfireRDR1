# HipfireRDR1 0.2.15 — точка прицела на основе 0.2.11

Версия возвращает механику выстрелов и расчёт цели из 0.2.11.
Калибровка после ПКМ и поправки из 0.2.14 удалены.
Добавлено только отображение цели выстрела маленькой белой точкой.

## Установка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe. Уберите другие копии этого мода.
3. Запустите игру, достаньте револьвер пешком стоя: точка должна появиться
   без предварительного нажатия ПКМ.
4. Стреляйте отдельными нажатиями ЛКМ. При ПКМ используется обычный прицел.

Нужны прежние RedHook 0.8 и предоставленный RDR.exe 1.0.40.57107.
Архивы игры менять не требуется. F7 отключает мод вместе с точкой.
Точка скрывается при ПКМ, Dead Eye, перезарядке, меню, потере фокуса,
убранном оружии и неподдерживаемых состояниях игрока.

## Что показывает точка

Мод проецирует на экран ту же мировую цель, которую 0.2.11 передаёт задаче
выстрела. Во время подготовки выстрела используется уже переданная цель;
между выстрелами она обновляется. Отдельной неподвижной метки в центре нет.
Точка выводится средствами движка и не включает режим прицеливания.

Это указатель цели задачи. Фактическая траектория пули и точка столкновения
не перехватываются: разброс, близкие препятствия и смещение относительно
ствола могут приводить к отклонению попадания. Точное совпадение точки с
попаданием и положение самого значка ещё требуют проверки в игре.

Правила очереди, тайминги, восстановление позы и остаточные обрывы серии
сохранены из 0.2.11. Удержание ЛКМ не добавляет повторных выстрелов.

## Проверено

Сборка Windows x64; прежние проверки стрельбы и очередей, включая 6/9/15
патронов; отображение без предварительного ПКМ, скрытие в запрещённых
состояниях, использование цели активного выстрела. Аргументы новых функций
проекции, текста и регистрации символа проверены на адаптерах из RDR.exe.
Саму игру в этой среде запустить нельзя; визуальная проверка не выполнена.
