# HipfireRDR1 0.2.18 — движение без задачи выстрела (экспериментальная)

В пользовательской проверке 0.2.17 Джон всё ещё останавливался.
Одной замены PistolHoldStand на PistolHoldRun оказалось недостаточно.
Точная причина остановки пока не доказана.

## Изменение

При начале выстрела в движении мод больше не создаёт TASK_SHOOT_AT_COORD
и не очищает текущие задачи игрока. Вместо неё выбирается PistolHoldRun
и задаётся координата через AI_GOAL_AIM_AT_COORD. Сам выстрел запускается
прежним перехватом игрового спуска: отдельный клик добавляет один запрос.
Нативный setter цели проверен по EXE: записывает координату и флаги,
не создавая задачу. Его третий аргумент — BOOL, здесь 0, а не строка.

После выстрела/отмены снимается только созданная модом цель; задачи
движения или перезарядки на этом пути не очищаются. Принудительного
задания скорости или перемещения персонажа нет.

Если движение начинается во время подготовки стоячего выстрела,
прежняя задача снимается один раз, затем сохраняются тот же клик и цель.
Новая задача выстрела при таком переходе не создаётся.

Стоячий путь с параметром задачи 0.25, очередь кликов, ограничения
патронов и рабочая точка RedHook сохранены. После начала движущегося
выстрела его способ запуска сохраняется до завершения текущего запроса.

## Установка и проверка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe. Уберите другие копии мода.
3. Проверьте привычную стрельбу стоя.
4. Удерживая W и продолжая идти, сделайте отдельные короткие клики ЛКМ без ПКМ.
5. Повторите при беге, затем при движении вбок и назад.

Нужны прежние RedHook 0.8 и предоставленный RDR.exe 1.0.40.57107.
Для точки: RedHook.ini, [DirectXHook], Disabled=false. F7 отключает мод.
Архивы игры менять не требуется. Стабильная 0.2.16 доступна в коммите 7680404.

## Проверено и не проверено

Сборка Windows x64 и проверки прежних сценариев пройдены. В модели оружия
проверены один выстрел при удержании ЛКМ, серии 6/9/15 отдельных кликов,
отсутствие задачи выстрела на движущемся пути, переход со стоячего пути,
очистка цели при ПКМ/F7/потере фокуса, перезарядке и потере управления.
Адаптеры задания/очистки цели проверены эмуляцией реального RDR.exe,
включая границы изменяемых полей.

Игра здесь не запускается. Работа выстрела через цель без задачи,
сохранение ходьбы/бега и правильная анимация ещё не подтверждены в игре.
Сборка экспериментальная. Остальные ограничения серий и попаданий сохраняются.

## Журнал

HipfireRDR1-Clicks.log: версия 0.2.18_taskfree_movement_experimental.
shot_backend backend=aim_goal означает путь без задачи выстрела;
backend=shoot_task — прежнюю стоячую стрельбу. motion_backend отмечает
переход, а motion записывает текущую скорость в начале/конце попытки.
confirmed по-прежнему означает уменьшение числа патронов.
