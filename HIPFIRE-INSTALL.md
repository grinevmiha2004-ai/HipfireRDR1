# HipfireRDR1 0.2.17 — стрельба в движении (экспериментальная)

Основа — подтверждённая пользователем 0.2.16 с точкой прицела.
Добавлен выбор штатного узла PistolHoldRun при движении вместо PistolHoldStand.
В движении мод перестаёт принудительно задавать и удерживать поворот тела.
После остановки выбирается прежняя стоячая поза. При начале/окончании
движения во время подготовки выстрела переключается поза без новой задачи
выстрела и без добавления клика в очередь.

В ресурсах подтверждены соответствующие rapid run aim-клипы. Некоторые
run fire-псевдонимы используют общий стоячий recoil-клип: мод допускает
его как продолжение выстрела, не перезапуская анимацию из-за имени файла.

## Установка и проверка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe. Уберите другие копии мода.
3. Сначала проверьте привычную стрельбу стоя.
4. Продолжая идти вперёд, сделайте несколько отдельных кликов ЛКМ без ПКМ.
5. Повторите при беге, затем проверьте движение вбок и назад.
6. Проверьте начало и остановку движения во время серии.

Один клик — один запрос выстрела. Удержание ЛКМ не добавляет повторов.
WASD распознаются как запрос движения; также читается горизонтальная
скорость персонажа. Собственные переназначения клавиш не перехватываются,
но движение уже идущего персонажа распознаётся по скорости.
Параметр задачи 0.25 и правила очереди из 0.2.11 сохранены.

Нужны прежние RedHook 0.8 и предоставленный RDR.exe 1.0.40.57107.
Для точки в RedHook.ini секция [DirectXHook], Disabled=false.
F7 отключает мод. Игровые архивы менять не требуется.

## Ограничения и журнал

Это экспериментальная поддержка движения. Игра здесь не запускается;
отсутствие остановки, правильная походка и поза при беге ещё не проверены.
Название узла и автоматические проверки не доказывают результат в игре.
При регрессии можно вернуть стабильную 0.2.16 из коммита 7680404.

HipfireRDR1-Clicks.log содержит версию 0.2.17_movement_experimental,
shot_pose с mode=run/stand, переключения motion_pose и выбранные клипы.
Счётчик патронов по-прежнему подтверждает фактический выстрел.
Старые ограничения серий и соответствия точки фактическому попаданию остаются.

Проверены сборка Windows x64, прежние сценарии очередей и прицела,
выбор позы при WASD/скорости, отсутствие принудительного поворота в движении,
переключение без повторной задачи и серии 6/9/15 в модели оружия.
Аргументы чтения скорости проверены на реальном адаптере RDR.exe.
