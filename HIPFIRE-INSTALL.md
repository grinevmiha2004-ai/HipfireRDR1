# HipfireRDR1 0.2.8 Recovery

Версия 0.2.7 ухудшила запуск выстрелов и заменена этой сборкой.
Отдельный клик ЛКМ добавляет один запрос; удержание не создаёт повторов.

## Установка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe файлом этой версии.
   Уберите другие копии HipfireRDR1 из папок загрузки модов.
3. Пешком, стоя с револьвером в руке, сделайте три коротких отдельных
   нажатия ЛКМ без ПКМ и дождитесь выполнения очереди.

Нужны прежние RedHook 0.8 и предоставленная версия RDR.exe 1.0.40.57107.
Игровые архивы и ScriptHook менять не нужно. Capture можно оставить.
F7 включает/выключает мод. ПКМ отменяет очередь.

## Исправления 0.2.8

- Убрано бессрочное ожидание сброса флага «персонаж стреляет».
  Если флаг остаётся включённым, ожидание ограничено 400 мс;
  перед новым выстрелом оставшаяся задача очищается.
- Возвращено короткое освобождение подтверждённой задачи из 0.2.6:
  минимум 300 мс от старта и 50 мс после расхода патрона.
  Ожидание полной тишины флага стрельбы из 0.2.7 убрано.
- Временный номер оружия -1 не удаляет очередь. До двух секунд
  используется последний известный номер оружия того же персонажа
  для проверки расхода патрона. Новые задачи при неизвестном номере
  не запускаются. Уже начатый выстрел продолжает учитываться.
- При возвращении другого оружия прежние запросы отменяются.
  Если номер не восстановился за две секунды, очередь также отменяется.

Сохранены путь позы, исправленный луч камеры и параметры задачи
из подтверждённой пользователем 0.2.4. Цель берётся с текущей камеры
при запуске выстрела. Спуск короткого клика сохраняется до расхода
патрона. Время следующего запроса — не менее 350 мс от предыдущего старта
и 100 мс от подтверждения, с отпусканием игрового спуска между запросами.

## Очередь и прерывания

Вместимость — 64 запроса, включая выполняемый. При заполнении новые
клики отклоняются. Укрытие, приседание, перезарядка, падение и временная
потеря управления приостанавливают запросы. Пока действует такое
состояние, мод не сбрасывает задачи и не задаёт направление корпуса.
При пустом оружии перезарядите его вручную, если игра не делает это сама.

Расход патрона проверяется до обработки прерывания и перед повторной
попыткой. Запрос без расхода патрона за две секунды повторяется после
отпускания спуска и восстановления допустимого состояния. После трёх
неудачных попыток очередь приостанавливается, сохраняя запросы.
Следующий отдельный клик возобновляет попытки и добавляет новый запрос.
ПКМ позволяет отменить очередь.

ПКМ, F7, пауза, потеря фокуса, кат-сцена, Dead Eye, смерть и смена
оружия/персонажа отменяют очередь. Остановка обновления скрипта также
может сбросить её. Неизвестная версия EXE отключает перехват.

## Проверка

Пройдены сборка и тесты быстрых кликов, удержания, зависшего флага
стрельбы с активной задачей и без неё, временного номера оружия -1,
позднего выстрела в момент такого перехода, смены оружия, перезарядки
и прерываний. Скомпилированный перехват проверен эмуляцией через код
ввода предоставленного EXE.

Версия 0.2.8 в запущенной игре ещё не проверена. Эти проверки не
подтверждают устранение всех случаев обычной анимации прицеливания.

HipfireRDR1-Clicks.log создаётся рядом с модом и перезаписывается при
запуске игры. При повторении проблемы сохраните его до следующего запуска.
Он записывает очередь, расход патронов, смену состояний, сброс зависшей
задачи и сведения об анимациях. Отдельный запуск Capture не требуется.
