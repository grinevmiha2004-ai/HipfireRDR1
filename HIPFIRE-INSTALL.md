# HipfireRDR1 0.2.7 Combat

Отдельное нажатие ЛКМ добавляет один запрос выстрела от бедра.
Удержание не добавляет повторов. Быстрые клики сохраняются в очереди.

## Установка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe файлом этой версии.
   Уберите другие копии этого мода из папок загрузки модов.
3. Пешком, стоя с револьвером в руке, сделайте три отдельных коротких
   нажатия ЛКМ без ПКМ и дождитесь выполнения очереди.
4. После этого проверьте те же нажатия во время перестрелки.

Нужны прежние RedHook 0.8 и предоставленная версия RDR.exe 1.0.40.57107.
Игровые архивы и ScriptHook менять не требуется. Capture можно оставить.
F7 включает/выключает мод. ПКМ отменяет очередь.

## Исправления

Сохранены путь позы, исправленный луч камеры, формула направления
персонажа и параметры задачи из подтверждённой пользователем 0.2.4.

- Спуск удерживается до подтверждения расхода патрона. Один флаг
  «персонаж стреляет» больше не отпускает его раньше времени.
- После расхода патрона мод ждёт окончания стрельбы перед освобождением
  задачи, вместо сброса позы через фиксированные 50 мс.
- Укрытие, приседание, перезарядка, падение, временно недостанное оружие
  и временная потеря управления приостанавливают очередь. Эти состояния
  не удаляют запросы и не возвращают обычную обработку ЛКМ.
- Пока действует такое состояние, мод не сбрасывает задачи и не задаёт
  направление корпуса. Возобновление ждёт устойчивой готовности оружия.
- Расход патрона проверяется до обработки прерывания и до повторной
  попытки. Поздний выстрел завершает прежний запрос.
- Направление камеры читается при фактическом запуске выстрела: очередь
  хранит число запросов, а не старые точки прицеливания до перемещения.

Если начатый запрос не израсходовал патрон за две секунды, мод отпускает
спуск, ждёт восстановления состояния и делает повторную попытку того же
запроса. После трёх неудачных попыток очередь приостанавливается без
удаления запросов. Следующее отдельное нажатие ЛКМ возобновляет попытки
и также добавляет один новый запрос. ПКМ отменяет всё ожидающее.

## Ограничения

Очередь вмещает 64 запроса, включая выполняемый. При заполнении новые
запросы отклоняются. Скорость зависит от готовности оружия. При пустом
оружии очередь ждёт патронов; при необходимости перезарядите вручную.

ПКМ, F7, пауза, потеря фокуса, кат-сцена, вход в Dead Eye, смерть,
смена оружия/персонажа или уход из поддерживаемого режима отменяют
очередь. Смена состояния игры после длительной остановки скрипта также
может сбросить её. Неизвестная версия EXE отключает перехват.

Пройдены сборка, тесты очереди и прерываний, поздних выстрелов,
перезарядки, повторных попыток, удержания и быстрых кликов. Проверена
эмуляция скомпилированного перехвата через код ввода предоставленного EXE.
Это не проверка в запущенной игре. Поведение 0.2.7 в реальной перестрелке
ещё требует проверки; устранение всех переходов к обычной анимации
прицеливания пока не подтверждено.

## Журнал

HipfireRDR1-Clicks.log создаётся рядом с модом и перезаписывается при
запуске игры. Если проблема повторится, сохраните его до следующего запуска.
Теперь он также записывает состояния, приостановку/возобновление,
попытки и сведения о выбранных анимациях. Отдельный запуск Capture
для этого журнала не нужен.
