# HipfireRDR1 0.2.6 Clicks

Один отдельный клик ЛКМ добавляет один запрос выстрела от бедра.
Удержание кнопки не добавляет повторов. Быстрые повторные нажатия
сохраняются в очереди и выполняются по готовности оружия.

## Установка

1. Закройте игру полностью.
2. Замените HipfireRDR1.red рядом с RDR.exe файлом этой версии.
   Уберите другие копии HipfireRDR1 из папок загрузки модов.
3. Пешком, стоя с револьвером в руке, сделайте три коротких отдельных
   нажатия ЛКМ без ПКМ и дождитесь выполнения очереди.
4. F7 включает/выключает мод. ПКМ отменяет очередь.

Используются прежние RedHook 0.8 и предоставленная версия RDR.exe
1.0.40.57107. Менять игровые архивы и ScriptHook не требуется.
Capture можно оставить установленным. Заменять мод нужно при закрытой игре.

## Изменения

Анимация, направление цели и параметры задачи сохранены из 0.2.4,
работу которой пользователь подтвердил. Версия 0.2.5 с повтором от
удержания оказалась неудачной и заменена.

В 0.2.6 добавлен перехват игрового запроса кнопки огня: после короткого
клика мод сохраняет игровой спуск до начала выстрела и отпускает его
перед следующим запросом. Физические нажатия считаются отдельно.
Следующий запрос запускается после подтверждения расхода патрона,
освобождения задачи и готовности оружия. Скорость зависит от оружия.
Цель запоминается с камеры при каждом нажатии. Вместимость очереди —
64 запроса, включая выполняемый; лишние нажатия при заполнении отклоняются.

ПКМ, F7, пауза, потеря фокуса, вход в Dead Eye, смена оружия или
персонажа отменяют очередь. При пустом оружии очередь ждёт патронов;
при необходимости перезарядите вручную. Если начатый запрос не привёл
к расходу патрона за две секунды, очередь отменяется без повторных
перезапусков анимации. Неизвестная версия EXE или несовместимый перехват
ввода отключают мод.

## Проверка и ограничения

Пройдены сборка, тесты очереди и подтверждения расхода патронов,
быстрых кликов, удержания, перезарядки и отмены. Скомпилированный
перехват проверен эмуляцией через реальный код запроса ввода из
предоставленного EXE. Это не заменяет проверку работы версии 0.2.6
в запущенной игре: она пока не проведена.

Если результат отличается от ожидаемого, сохраните созданный рядом
с модом HipfireRDR1-Clicks.log до следующего запуска игры. Он содержит
нажатия, начало задач, подтверждение расхода патронов и причину отмены.
