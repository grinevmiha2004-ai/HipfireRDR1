# HipfireRDR1 0.2.16 — прицел через отрисовку RedHook

Механика стрельбы и расчёт цели остаются из 0.2.11.
В 0.2.15 точка не появилась в пользовательской проверке. Вместо символа
через игровой отладочный шрифт теперь используется RH_DrawRect из RedHook 0.8.
Белая метка размером 3x3 пикселя окружена тёмной рамкой размером 5x5 пикселей.
Оба прямоугольника центрируются на проекции цели задачи выстрела.

## Установка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe. Уберите другие копии этого мода.
3. Запустите игру и достаньте револьвер пешком стоя, без нажатия ПКМ.
4. Точка должна отображаться до первого выстрела; стреляйте отдельными кликами ЛКМ.

Нужны прежние RedHook 0.8 и предоставленный RDR.exe 1.0.40.57107.
Для графики RedHook в RedHook.ini должен быть включён его штатный рендерер:
секция [DirectXHook], параметр Disabled=false. Это стандартное значение;
мод сам не изменяет настройки RedHook. Игровые архивы менять не требуется.

При ПКМ остаётся обычный прицел; F7 отключает мод и точку.
Точка скрывается в меню, Dead Eye, при перезарядке, убранном оружии,
потере фокуса и других неподдерживаемых состояниях игрока.

## Журнал

HipfireRDR1-Clicks.log содержит версию 0.2.16_dot_rect и наличие функции
отрисовки RedHook (renderer=1). Строки reticle status показывают скрытие
из-за контекста, недопустимые координаты или submitted_redhook_rect —
передачу прямоугольников в очередь отрисовки. Последний статус подтверждает
вызов функции, но не доказывает видимость изображения на экране.

## Проверки и ограничения

Сборка Windows x64 и прежние проверки стрельбы пройдены. Проверены
отображение без предварительного ПКМ, отсутствие смещения центра метки,
размер при разных разрешениях, скрытие при недопустимых условиях.
Аргументы RH_DrawRect и преобразование координат в прямоугольники проверены
эмуляцией реальных функций из предоставленной RedHook.dll.
В этой среде игра не запускается: визуальная проверка ещё не выполнена.

Метка показывает цель игровой задачи. Фактическая траектория пули и точка
столкновения не перехватываются: разброс и близкие препятствия могут давать
отклонение попадания. Остаточные обрывы серий из 0.2.11 сохранены.
