# HipfireRDR1 0.2.5 Series — проверка серии при удержании

Пользователь подтвердил правильные направление и анимацию в 0.2.4.
В 0.2.5 сохранены её узел, клип, формула цели и параметры одного выстрела.
Добавлены повторные запросы выстрела при удержании ЛКМ.

## Установка

1. Закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe новым файлом.
3. Пешком, с револьвером в руке, удерживайте ЛКМ без ПКМ.
   Продолжайте удержание для следующих выстрелов. Отпустите для остановки.
4. F7 включает/выключает мод; ПКМ отменяет действие мода.

Для первого фактического выстрела продолжайте удерживать кнопку, как
в подтверждённой 0.2.4. По пользовательскому захвату он начинается
примерно через 265–280 мс. Очень короткий щелчок по-прежнему может
не дать выстрела: отдельная фиксация игрового ввода здесь не добавлялась.

## Поведение серии

Каждый запрос использует прежние задачу и окно 300 мс. Следующая попытка
разрешается не раньше чем через 350 мс и только когда движок перестал
считать персонажа стреляющим/перезаряжающимся. Скорость не превышает
готовности текущего оружия. Новая цель читается с камеры для каждой попытки.

Один ранний повторный клик сохраняется как запрос до 500 мс, если оружие
ещё занято. Длинная очередь отложенных выстрелов не создаётся.

ПКМ, F7, пауза, потеря фокуса, вход в Dead Eye, смена оружия/персонажа
сбрасывают повтор. После отмены нужно отпустить и снова нажать ЛКМ.
Перезарядка при удерживаемой кнопке приостанавливает следующие запросы;
после её завершения они снова могут запускаться.

Проверены сборка и тесты реального скриптового цикла: серия из одного
удержания, готовность оружия, отпускание, повторные нажатия, перезарядка,
отмена, смена оружия, истечение буфера и сохранение исправленного луча.
В настоящей игре серия 0.2.5 ещё не проверена.

Нужен прежний RedHook 0.8. Загрузчики, игровые архивы и Capture менять
не требуется. Для нового лога: F10, несколько секунд удержания ЛКМ,
отпустить ЛКМ, F11; файл HipfireRDR1-Capture.jsonl.
