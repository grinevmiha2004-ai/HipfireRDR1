# HipfireRDR1 0.2.9 Full Series

Один отдельный клик ЛКМ добавляет один запрос выстрела от бедра.
Удержание не добавляет повторов. Очередь вмещает 64 запроса и
выполняется с учётом реально оставшихся патронов и перезарядки.
Серии из 6, 9 и 15 отдельных кликов проверены на модели оружия.

## Установка

1. Полностью закройте игру.
2. Замените HipfireRDR1.red рядом с RDR.exe файлом этой версии.
   Уберите другие копии HipfireRDR1 из папок загрузки модов.
3. Пешком, стоя с заряженным револьвером в руке, сделайте шесть
   коротких отдельных нажатий ЛКМ без ПКМ и дождитесь выполнения очереди.
   Для оружия с большей вместимостью можно добавить больше нажатий.

Нужны прежние RedHook 0.8 и предоставленная версия RDR.exe 1.0.40.57107.
Игровые архивы и ScriptHook менять не требуется. Capture можно оставить.
F7 включает/выключает мод. ПКМ отменяет очередь.

## Исправления 0.2.9

- Поза проверяется после постановки задачи выстрела. Если задача
  заменила узел от бедра обычным прицеливанием, мод повторно выбирает
  нужный узел перед подачей игрового спуска.
- Учитывается как сам узел удержания, так и известный rapid-клип:
  работающий клип стрельбы не перезапускается только из-за смены листа
  дерева действий. Число ранних исправлений ограничено двумя на попытку.
- Если поза не включилась, спуск не подаётся, задача сразу освобождается,
  а запрос сохраняется для повторной попытки.
- Ожидание несработавшего выстрела сокращено с 2000 до 800 мс.
  По окончании этого срока задача и поза освобождаются до следующей
  попытки, с сохранением наблюдения за возможным поздним расходом патрона.
- Постоянная остановка очереди после трёх неудачных попыток убрана.
  Повтор продолжается автоматически; каждая третья ошибка даёт паузу
  500 мс. Дополнительный клик для возобновления не требуется.

Путь позы, исправленный луч камеры и параметр задачи 0.25 сохранены
из подтверждённой пользователем 0.2.4. Цель берётся с текущей камеры
при запуске выстрела. Мод читает расход патронов, сам их не добавляет
и не создаёт отдельные пули. Темп зависит от выполнения игровых задач.

## Очередь и прерывания

Максимум очереди — 64 запроса, включая выполняемый. Лишние клики при
заполнении отклоняются. При пустом оружии очередь ждёт патронов;
при необходимости перезарядите вручную. Нажатия сверх текущего заряда
не превращаются в дополнительные патроны: оставшиеся запросы ждут
перезарядки. Фиксированного предела в три успешных выстрела нет.

Укрытие, приседание, перезарядка, падение и временная потеря управления
приостанавливают запросы. Пока действует такое состояние, мод не
сбрасывает его задачи и не задаёт направление корпуса. Временный номер
оружия -1 допускается до двух секунд для учёта уже начатого выстрела;
новая задача до восстановления известного номера не запускается.

ПКМ, F7, пауза, потеря фокуса, кат-сцена, Dead Eye, смерть и смена
оружия/персонажа отменяют очередь. Остановка обновления скрипта также
может сбросить её. Неизвестная версия EXE отключает перехват.

## Проверка и журнал

Пройдены сборка и тесты полных серий на 6/9/15 патронов, коротких
кликов, удержания, замены позы задачей и ранним игровым обновлением,
отказа включения позы, освобождения неудачной задачи через 800 мс,
автоматического продолжения после трёх ошибок, поздних выстрелов,
перезарядки, прерываний и временного номера оружия -1.
Скомпилированный перехват проверен эмуляцией через код ввода EXE.

Это не проверка в запущенном RDR. Полное устранение зависаний и
всех случаев обычного прицеливания в реальном бою пока не подтверждено.

HipfireRDR1-Clicks.log создаётся рядом с модом и перезаписывается при
запуске игры. При повторении проблемы сохраните его до следующего запуска.
Он также содержит pose_repair и released_failed для проверки новых
переходов. Отдельный запуск Capture не требуется.
