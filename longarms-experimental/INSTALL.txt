HipfireRDR1 — Longarms Experimental 06 / Autoreload fix
Для исходного RDR.exe пользователя: 1.0.40.57107.

Эта сборка исправляет найденную ошибку автоперезарядки.
СТРЕЛЬБА НА ХОДУ ОСТАЁТСЯ НЕРЕШЁННОЙ: код ходьбы сохранён из 05.

Причина ошибки перезарядки:
После подтверждения последнего патрона тип оружия сохранялся из
временной ячейки стека +6C. К тому моменту оригинальный скрипт уже
переиспользовал её под флаг position_valid. Вместо реального типа
оружия запоминались 0/1, а следующий шаг отменял запрос из-за
несовпадения. Теперь актёр и оружие читаются из постоянных полей
Controls +768/+76C. Сама штатная функция перезарядки не меняется.
Для длинноствольного оружия добавлена строка журнала:
autoreload armed ... stable_state=1
Успешный запрос по-прежнему отмечается autoreload requested.

Установка:
Закрой игру, сохрани текущий HipfireRDR1.red вне папки игры и замени
файлом из корня архива. RDR.exe и RedHook менять не нужно.
Диагностический HipfireRDR1-Capture.red должен быть удалён.

Проверь перезарядку стоя: полностью израсходуй магазин, отпусти ЛКМ
и не нажимай R. Если перезарядка не началась, пришли новый
HipfireRDR1-Clicks.log и название оружия. Проверь также револьвер.

По ходьбе:
Повторное назначение позы и увеличение ожидания из 05 в игре не
устранили pose_activation_timeout. Для дальнейшего разбора полезны
само игровое дерево default_character (корень default_character_Main)
и связанные винтовочные анимационные ресурсы. EXE и SDK уже есть.
Если не знаешь, где находятся эти данные, пришли список/скриншот
файлов и папок в корне игры — по нему можно уточнить нужный архив.

69 автоматических проверок прошли, включая исполнение настоящей
инструкции скрипта, затирающей временную ячейку, воспроизведение
отказа 05, устойчивое сохранение типа для всех обычных видов оружия
и вызов настоящего кода перезарядки в эмуляции. Поведение части
игровых объектов моделировалось; сама сборка в игре ещё не проверена.

Остальное поведение 05 сохранено. Для отката при закрытой игре
верни сохранённый HipfireRDR1.red.
